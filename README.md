# Lab-project---Yuval.-Offek-Yuval

Our project is a tool for Airbnb hosts, used to find the optimal price in order to maximize host revenue based on data analysis, seasonality factors and property details.

## How to run
1. Insert the SAS token in the first cell to load the Airbnb data.
2. Run the notebook from start to finish.
3. The UI is located in the last code cell.

## Using the UI
In the last cell, the user can insert:
- Property details
- Desired month(s)
- Price range (min/max/step)
- Target peak price (starting point)

## Output
After running the UI cell, the output shows for each month:
- Optimal weekday price
- Optimal weekend/holiday price
- Predicted occupancy percentage
- Estimated revenue

The user is encouraged to experiment with different months and price ranges.
